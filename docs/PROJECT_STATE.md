## Product Shape

Ghostline is a deterministic 2D top-down time-trial racer and RL sandbox. The
important design goal is one shared driving path:

- human keyboard input,
- replay playback,
- ghost rendering,
- scripted evals,
- RL policies.

All of them produce or consume the same control-rate `Action` stream.

## Current Truth

Implemented:

- Fixed clocks: 120 Hz physics, 60 Hz control, render interpolation.
- `Action` dataclass is the only input path.
- `physics_v4` car feel: local-frame grip, high-speed understeer, handbrake drift,
  boost pads, swept wall collision, wall stats, and raycasts.
- Deterministic `Simulation.reset/step/snapshot/restore/state_hash`.
- One current track: `track_01_easy_loop`, generated by `tools/build_track_01.py`.
  It has filled asphalt/infield surfaces, kerb-style walls, checkered finish, four
  checkpoints, two boost pads, and an authored render/eval racing line.
- JSON track schema v4 with render-only `surface_outer`, `surface_inner`, and
  `racing_line`.
- Ordered directed checkpoints, finish gate, and tick-derived lap timing. Reported
  `lap_time` is sub-tick: the finish crossing is interpolated within its control step
  via `finish_fraction` (B9), so it has ~ms precision. `lap_ticks` stays the canonical
  integer for the state machine, replay validation, and RL reward; the sub-tick value
  is reporting-only and never enters env reward/termination. `TIMING_VERSION`
  ("timing_v2") marks metrics / RL rollout records carrying sub-tick times.
- Replay recording/playback with canonical action streams plus derived frame cache.
- Replay/metrics physics compatibility guard via `PHYSICS_VERSION` plus
  deterministic `CarPhysics` fingerprint.
- Persistent last/best replay files, visual best ghost, ghost trail, `G` toggle, and
  live delta.
- Pygame renderer/HUD/debug view, skid marks, live tuning keys, and fullscreen
  rendering with `F11` windowed toggle.
- Headless eval harness for drift feel and the Track 1 scripted lap.
- RL wrapper and training stack under `momentum_lab/rl/`: `GhostlineEnv`,
  versioned rewards, rollout artifacts, PPO training/eval, warm-start curriculum,
  keep-best checkpoint selection, ranked analytics, static SVG reports, and trace
  comparison.
- Interactive RL replay/story viewer (`momentum_lab/rl/visualizer.py`, B7.6): a
  read-only `python -m momentum_lab.rl.visualizer` CLI that selects saved runs
  (top-N, run id, model/reward/policy/status, or a curated `--story progression`) and
  writes a single self-contained `runs/rl/analysis/replay_viewer/index.html` with
  overlay/scrub playback, layer toggles, a throttle/brake/steer/drift decision
  timeline, and sector-vs-reference deltas. Built on the same `analytics.scan_runs`
  artifacts; does not replace the static ranked report.
- Viewer coverage extensions (B7.6b): an opt-in training-trace recorder
  (`--save-trace-checkpoints` / `--trace-eval-freq`, off by default) that saves
  per-step deterministic-eval rollout artifacts (`policy=ppo_trace`) for an
  intra-run "learning over steps" timeline, and a viewer `--reevaluate <model.zip>`
  that materializes a missing rollout from a saved model (env config rebuilt from
  the manifest, or the policy's action space when absent). Both reuse the existing
  rollout/eval/selection code; re-eval is gated on stable-baselines3.
- Portfolio export (`momentum_lab/portfolio_export.py`, GL-02/GL-03): a read-only
  `python -m momentum_lab.portfolio_export --out <dir>` CLI that bundles the reused
  replay viewer and static analytics, the canonical Track 1 JSON, and the two
  benchmark replay artifacts (run `970622` Ghostline AI, run `750982` Michi/dev)
  into a portable `replay_viewer/ analysis/ data/` tree the website hosts under
  `/ghostline/...`. It copies the existing HTML (does not regenerate it), writes
  `data/manifest.json` (track/physics/timing versions plus the two locked benchmark
  rows), locates the benchmark runs by stable id via `analytics.scan_runs` and
  verifies their lap time / walls still match, then audits the HTML for
  `file://`/absolute/dead asset references so it serves cleanly off a static server.

## Architecture Invariants

- `Simulation.step()` takes an `Action`, not `dt`.
- `core/` must not import pygame, input polling, rendering, file I/O, wall-clock
  time, RL training code, or generated artifacts.
- Sim time is `tick * CONTROL_DT`; no wall-clock reads inside the sim.
- Keep same-machine determinism. Do not use global random. If randomness is added,
  seed it from `reset(seed)` and snapshot it.
- Track geometry is immutable once loaded.
- Snapshot/restore must include all mutable state needed for branching and replay
  validation.
- Derived metrics such as slip angle, drift time, path distance, wall stats, and lap
  progress must not feed back into physics. Sub-tick `lap_time` is likewise
  reporting-only: it must never enter the RL env reward or termination (those read the
  integer `lap_ticks` and the boolean finish flag).
- Replays and RL rollouts use seed + initial state + action stream as canonical
  truth. Cached frames are visualization caches.
- Changing physics constants or behavior should bump `PHYSICS_VERSION` and update
  replay/eval expectations.
